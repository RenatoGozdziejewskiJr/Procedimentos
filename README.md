# Notes about the Procedures and Notes repository

This repository contains practical procedures and technical notes organised by subject in the [`docs/`](docs/) directory.

## Documentation

- Browse the documentation source in [`docs/`](docs/).
- Follow the [documentation standards](DOCUMENTATION_STANDARDS.md) when creating or substantially revising documents.

## Preview the documentation

Install the dependencies and start the local preview:

```powershell
python -m pip install -r requirements.txt
python -m mkdocs serve
```

Build the static site with:

```powershell
python -m mkdocs build
```
