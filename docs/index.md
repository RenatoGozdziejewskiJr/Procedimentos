# About

This documentation contains practical procedures and technical notes organised by subject. The canonical version of each document is written in British English (EN-GB). Where the source material was in Portuguese, a Brazilian Portuguese (PT-BR) companion is provided and linked from its English counterpart.

Use the navigation menu to browse the available topics. Portuguese translations use the `-pt-br` filename suffix.

The Markdown files in this directory are the source of truth for the generated site.
